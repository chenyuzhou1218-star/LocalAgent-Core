# LocalAgent

Windows local Agent workstation with a PySide6 UI, Ollama, and a generic OpenAI-compatible adapter for OpenAI, DeepSeek, MiniMax, Doubao/Volcengine, Qwen, and other compatible APIs, plus Computer Use, file tools, project tools, and permission control.

## Start

Install Python 3.12+, then run:
python -m pip install -r requirements.txt

Copy config.example.json to config.json, configure a provider, and double-click start.bat.

## Safety

Do not commit config.json, API keys, history, logs, screenshots, browser profiles, or workspace data. Computer Use and terminal tools have elevated capabilities.
